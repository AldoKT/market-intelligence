# SIGNAL Backend v1

FastAPI application layer for the SIGNAL Market Intelligence prototype.

This backend **does not call Sectors API**. It only reads the JSON payloads
generated by `signal_build_payloads_v1.py`.

## Recommended folder layout

```text

├── signal_backend_v1\
│   ├── app\
│   ├── tests\
```

## 1. Install dependencies

From PowerShell:

```powershell
cd "D:\Lain-lain\Sector\signal_backend_v1"

python -m pip install -r requirements.txt
```

## 2. Choose payload snapshot

For the historical demo with active investigations:

```powershell
$env:SIGNAL_PAYLOAD_DIR="D:\Lain-lain\Sector\signal_product_payloads_v1_demo"
```

For latest snapshot:

```powershell
$env:SIGNAL_PAYLOAD_DIR="D:\Lain-lain\Sector\signal_product_payloads_v1_latest"
```

## 3. Run API

```powershell
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Open:

```text
http://127.0.0.1:8000/docs
```

The Swagger page lets you test each endpoint interactively.

## API endpoints

```text
GET /api/health
GET /api/manifest
GET /api/overview
GET /api/investigations
GET /api/investigations/{symbol}
GET /api/investigations/{symbol}/summary
GET /api/investigations/{symbol}/activity
GET /api/investigations/{symbol}/context
GET /api/investigations/{symbol}/history
GET /api/methodology
```

### Investigation query parameters

`GET /api/investigations` supports:

```text
state=ESTABLISHED
peer_group=basic_materials
context_scope=STOCK_SPECIFIC_ACTIVITY
active=true
q=ANTM
```

Example:

```text
/api/investigations?active=true&state=DEVELOPING
```

## 4. Run tests

```powershell
python -m pytest -q
```

## Architecture

```text
SIGNAL research engine
        ↓
signal_build_payloads_v1.py
        ↓
JSON Product Contract
        ↓
PayloadRepository
        ↓
FastAPI
        ↓
React / TypeScript frontend
```

The API is intentionally read-only. Detector methodology stays outside the
application layer so UI/backend changes cannot silently alter research logic.
